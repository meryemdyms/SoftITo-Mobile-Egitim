
# Araç Kiralama Platformu — Agent Kuralları

Bu paket Flutter uygulama **kaynak kodu değil**, proje yönergeleridir.

1. Kök `project.md` ürün ve mimari anayasasıdır.
2. Kök `AGENTS.md` agent'ın kullanım yönlendirmesidir.
3. `.agents/skills/<skill>/SKILL.md` konuya özel çalıştırma kurallarıdır.
4. Var olan Flutter projenizin köküne klasör hiyerarşisini koruyarak kopyalayın.
5. Agent'a şu talimatı verin: `Önce project.md ve AGENTS.md dosyalarını oku. İsteğimle ilgili skill dosyalarını seç, kurallara uyarak uygula; kapsam dışına çıkma. Koddan sonra format/analyze/test sonuçlarını raporla.`

**Not:** IDE/agent türüne göre `.agents/skills` keşif yolu değişebilir; `AGENTS.md` bu nedenle doğrudan dosya yollarını listeler.
