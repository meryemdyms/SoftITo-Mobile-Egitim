# Testing & Quality

## Genel kurallar

- Kod değişikliğinden sonra analiz çalıştır.
- İş kuralları için unit test yaz.
- Önemli ekranlar için widget testlerini kullan.
- Mevcut çalışan özellikleri bozma.
- Gereksiz bağımlılık ekleme.

## Öncelikli testler

### Habit

- Alışkanlık oluşturma
- Günlük ilerleme kaydetme
- Hedef tamamlama
- Kısmi ilerleme
- Streak hesaplama
- Planlanmamış günlerin kontrolü

### Puzzle

- Parça sayısı hesaplama
- Rastgele sıra oluşturma
- Tekrarlanan parça kontrolü
- Günlük tek parça kuralı
- Eksik yapboz davranışı
- Tam yapboz keşfi

### Analytics

- Başarılı gün sayısı
- Tamamlama yüzdesi
- Toplam ilerleme
- Süreç sonu raporu
- Geçmiş verilerin korunması

- flutter test
